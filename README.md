# みたか暮らし相談室

三鷹市周辺で、暮らしの困りごとを「相談 → 対応 → 手配 → 立会い → 専門家への橋渡し」まで支える地域向けの民間サービスサイトです。運営は株式会社サンアローズです。

主な対象は、スマホ、草刈り、買い物、住まいの小さな困りごと、業者探し・見積確認・立会い、見守り、実家・空き家、家族・相続前の整理などです。

## ブログ運用

CMSは使わず、`activities.json` と `activities/` 配下のHTMLで更新します。

トップページには `activities.json` の日付順で最新3件が表示されます。

```json
{

  "category": "スマホ",

  "image": "assets/activities/example.jpg",
  "alt": "画像の説明",

}
```

## 表示・運用上の基本ルール

- 三鷹市や地域包括支援センターの行政サービスと誤認されないよう、「株式会社サンアローズが運営する民間サービス」と明示する。
- 三鷹市内のスマホ相談は無料。
- パスワード、暗証番号、金融情報は預からない。
- 料金が発生する作業は、原則として事前に内容・料金・実費を案内する。
- 法律、税務、登記、医療などの専門判断・手続代行は行わず、必要に応じて専門家へつなぐ。
- 電気工事については、第二種電気工事士資格だけで事業上の登録要件が満たされるとは限らないため、登録等が必要な工事は専門業者へつなぐ。
- 介護保険サービス、医療行為、身体介助を提供するサービスとして表示しない。
- 業者選び・見積確認は、施工品質や適正価格を保証する表現にしない。
